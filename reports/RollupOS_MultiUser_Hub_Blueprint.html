RollupOS — Multi-User Android Mini-App Hub

Google Identity Auth • Dynamic On-Phone Admin Switchboard • Per-User Isolated Storage • Multi-Team ESPN Fantasy Manager

1. Executive Overview & Multi-Tenant Architecture

RollupOS solves "90-app clutter" by installing a single Android WebAPK Super-App shell that dynamically loads authorized mini-apps, enforces per-user Google authentication, and isolates every user's data and API keys into strict namespaces (rollup::v1::u::<email>::app::<app-id>::*).

Architectural Layer File / Component Multi-User & Security Role
1. Mobile Launcher & Admin Switchboard index.html, manifest.json, sw.js Handles Google Sign-In, renders only the mini-apps authorized for the signed-in email, provides the 👑 Admin Mode permission matrix, and includes 1-tap 👁️ Preview as User testing.
2. Multi-Tenant Bridge SDK bridge/rollup-bridge.js Injected into every mini-app. Provides RollupBridge.auth, isolated per-user storage (RollupBridge.storage), per-user app config (RollupBridge.user), Phone Secret Vault (RollupBridge.vault), Camera, and File Export.
3. Flagship Mini-App: The League Pro apps/fantasy-manager/index.html
data/league_945552.json		 Multi-user ESPN Fantasy Manager synced with all 12 teams in Weekend Warriors (#945552). Each user selects their own team, toggles their own Protected Core players, stars Free Agents to their private Watchlist, and simulates roster moves in their own isolated sandbox.
4. CLI & GitHub Cloud Publisher rollup.py One-command local server (serve), live 12-team ESPN sync (sync-fantasy), new mini-app scaffolding (create), user authorization (authorize), and GitHub deployment (publish).
